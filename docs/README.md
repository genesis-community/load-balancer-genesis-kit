## Getting Started

If you're new to the Load Balancer Genesis Kit, we recommend starting with the following:

1. Read the [README.md](../README.md) for an overview of the kit
2. Follow the [Deployment Guide](deployment.md) to deploy your first load balancer
3. Consult the [Configuration Guide](configuration.md) for detailed configuration options

## Features

The Load Balancer Genesis Kit supports the following features:

- **vip**: Deploy with a VIP for high availability
- **static-ips**: Use static IPs for load balancer instances
- **cf**: Configure for Cloud Foundry integration

## Addons

The Load Balancer Genesis Kit provides the following addons:

- **cf**: Configure load balancers interactively
- **rc**: Generate and upload runtime configs for HAProxy
- **st**: View detailed status of your load balancer
